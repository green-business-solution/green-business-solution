# Templates

This folder contains starter templates for repeatable project artifacts.

## Starter Files

- `AGENTS.md`
- `AGENT_WORKFLOW.md`
- `ARCHITECTURE.md`
- `RESOURCE_MAP.md`
- `TASK_LIST.md`
- `ADR.md`
- `review-evidence.md`
- `browser-credential-boundary.md`

Copy a template before filling it in.
Keep completed project docs in the repo root, `docs/`, or `ADRS/` as appropriate.
