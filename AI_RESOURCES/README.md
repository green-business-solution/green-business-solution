# AI Resources

This folder contains reusable assets that help agents work inside this project.

## Folders

- `Skills/`: project-specific repeatable workflows that are too specific for global skills.
- `Scripts/`: notes or helpers for repeatable agent operations that do not belong in production scripts.
- `Templates/`: reusable templates for ADRs, review evidence, prompts, reports, issues, and generated artifacts.

Production code, deployment scripts, selector scripts, and data tooling should stay in the normal source tree unless they are agent-only support assets.
